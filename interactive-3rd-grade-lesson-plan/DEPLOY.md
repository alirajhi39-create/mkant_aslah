# نشر درس «مكانة الصلاة» على Vercel + السجل المشترك

## ١. لماذا يلزم سجل مشترك؟
كل جهاز يحفظ نسخة محلية في المتصفح. ليظهر إنجاز جميع الطلاب في **لوحة المعلم على جهاز واحد**، يرسل التطبيق نسخة تلقائية إلى قاعدة بيانات مشتركة كلما تقدّم الطالب أو سلّم عمله.

## ٢. تفعيل السجل المشترك (مرة واحدة) — الطريقة الأسهل
1. افتح مشروعك في Vercel.
2. اذهب إلى **Storage** (أو **Marketplace**) ← **Create Database** ← اختر **Upstash Redis**.
3. أنشئ قاعدة مجانية واربطها بهذا المشروع (Connect Project).
4. سيتعرّف التطبيق تلقائيًا على المتغيرات `KV_REST_API_URL` و`KV_REST_API_TOKEN` أو `UPSTASH_REDIS_REST_*`.
5. اضغط **Redeploy**.

## ٢-ب. الطريقة اليدوية
1. اذهب إلى [upstash.com](https://upstash.com) وأنشئ قاعدة **Redis** مجانية باسم `salah-lesson`.
2. من تبويب **REST API** انسخ:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
3. أضفهما في Vercel ← Settings ← Environment Variables ثم أعد النشر.

## ٣. إعدادات Vercel
افتح المشروع في Vercel → **Settings → Environment Variables** وأضف:

| الاسم | القيمة |
| --- | --- |
| `UPSTASH_REDIS_REST_URL` | رابط REST المنسوخ |
| `UPSTASH_REDIS_REST_TOKEN` | رمز REST المنسوخ |
| `TEACHER_PASSWORD` | كلمة سر المعلم (الافتراضية `139613`) |

ثم أعد النشر: **Deployments → Redeploy** (مع إلغاء استخدام الكاش).

> يدعم التطبيق أيضًا أسماء Vercel KV: `KV_REST_API_URL` و`KV_REST_API_TOKEN`.

## ٤. التحقق من التفعيل
- افتح `/api/health` على موقعك؛ يجب أن يظهر: `{"ok":true,"configured":true,...}`.
- افتح الدرس على جهاز طالب، اكتب اسمه وصفّه، وأكمل محطة.
- افتح لوحة المعلم (كلمة السر) وستجد الطالب ضمن السجل المشترك.

## ٥. كيف يعمل التجميع؟
- الطلاب لا يسجّلون دخولًا بريدًا إلكترونيًا؛ يتعرّف التطبيق على جهاز الطالب برمز محلي.
- كل محطة/درجة تُرسل تلقائيًا إلى السجل المشترك (`POST /api/class/:code/student`).
- سجلّ المعلم يُقرأ من الخادم (`POST /api/class/:code/roster`) مع التحقق من كلمة السر.
- رمز الصف الافتراضي `SALAH-3-1` ويجمع الفصلين ٣/١ و٣/٢ في لوحة واحدة. غيّره من لوحة المعلم فقط إذا أردت فصل بيانات صف آخر (يجب ضبطه على أجهزة الطلاب أيضًا).
- زر **«تحديث»** في اللوحة يعيد القراءة فورًا، وهناك تحديث تلقائي كل ٢٠ ثانية.

## ٦. النشر
### عبر GitHub
1. ارفع المشروع إلى مستودع GitHub.
2. في [vercel.com](https://vercel.com): **Add New → Project** واختر المستودع.
3. Vercel يكتشف Vite تلقائيًا، وملف `vercel.json` يضبط الإعدادات.
4. أضف متغيرات البيئة أعلاه، ثم **Deploy**.

### عبر سطر الأوامر
```bash
npm i -g vercel
vercel
vercel --prod
```
ثم أضف متغيرات البيئة من لوحة Vercel وأعد النشر.

## ٧. بدون سجل مشترك
يبقى الدرس يعمل بالكامل، وتُحفظ بيانات كل جهاز محليًا، وتظهر رسالة في نهاية الدرس ولوحة المعلم توضح أن السجل المشترك غير مفعّل.

## ٨. ملاحظات
- لا تشارك كلمة سر لوحة المعلم مع الطلاب.
- أسماء الطلاب تُخزّن في قاعدة بياناتك الخاصة (Upstash) ولا تُرسل لخدمات أخرى.
- الصور والأصوات مضمّنة داخل التطبيق، ولا تحتاج إعدادًا.
