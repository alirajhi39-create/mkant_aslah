# نشر درس «مكانة الصلاة» على Vercel

## الطريقة الأسرع
1. ارفع المشروع إلى مستودع GitHub.
2. افتح [vercel.com](https://vercel.com) واضغط **Add New → Project**.
3. اختر المستودع. سيتعرّف Vercel على إعدادات Vite تلقائيًا:
   - Build Command: `npm run build`
   - Output Directory: `dist`
4. اضغط **Deploy**، ثم شارك الرابط الناتج مع الطلاب.

ملف `vercel.json` في المشروع يضبط هذه الإعدادات مسبقًا، ولا يحتاج المشروع إلى متغيرات بيئة.

## الطريقة عبر سطر الأوامر
```bash
npm i -g vercel
vercel
vercel --prod
```

## ملاحظات مهمة
- التطبيق صفحة واحدة (SPA) ولا يحتاج قواعد بيانات؛ لذلك يعمل على الاستضافة الثابتة في Vercel.
- بيانات الصف تُحفظ في متصفح كل جهاز (localStorage).
- لتجميع أعمال الطلاب من أجهزتهم: بعد إرسال الطالب، انسخ «رابط تسليم المعلم» وأرسله لك. افتح الرابط وأدخل كلمة السر **139613** ليُضاف العمل إلى سجلّ الصف على جهازك.
- يمكن لكل طالب البدء من زر «طالب جديد»، أو «بدء الدرس من جديد لطالب آخر».
- لا تشارك كلمة سر لوحة المعلم مع الطلاب.
