# مكانة الصلاة — درس تفاعلي

درس تفاعلي لمادة الدراسات الإسلامية، الصف الثالث الابتدائي (بنين)، مع لوحة معلم وسجل مشترك اختياري.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## النشر على Vercel

1. يجب أن يكون **جذر المستودع** هو المجلد الذي يحتوي مباشرة على:
   `package.json` و`index.html` و`api/` و`server/` و`src/` و`vercel.json`.
2. لا تُرفع المجلد الأب الذي يحتوي مسافة أو قوسين في اسمه (مثل `interactive-3rd-grade-lesson-plan (1)`)،
   لأن Vercel يستخدم مسار الملفات في أسماء دوال الخادم ويحكم على الاسم بأنه غير صالح.
3. من إعدادات المشروع في Vercel: **Root Directory** يجب أن يشير إلى مجلد المشروع الصحيح.
4. أضف متغيرات قاعدة البيانات (Supabase أو Neon) كما في `DEPLOY.md`.
5. أعد النشر: **Deployments → Redeploy**.
6. قبل الرفع يمكن تشغيل فحص سريع:

```bash
node tools/preflight.mjs
```

## تفاصيل قاعدة البيانات والصلاحيات
راجع `DEPLOY.md`.
